# IBM Data Science Projects

Hands-on lab projects completed as part of the **IBM Python for Data Science, AI & Development** course.

## 📊 Project 1 — Stock & Revenue Analysis Dashboard

Analyzed historical stock and revenue data for **Tesla (TSLA)** and **GameStop (GME)** using Python.

**Skills used:**
- Web Scraping with `BeautifulSoup` & `requests`
- Data manipulation with `pandas`
- Interactive visualizations with `plotly`

**Tasks completed:**
- Extracted stock data using `yfinance`
- Scraped quarterly revenue from Macrotrends
- Built an interactive dashboard with dual subplots

## 🛠️ Tech Stack
`Python` `Pandas` `Plotly` `BeautifulSoup` `yfinance` `Jupyter Notebook`
